# 阅读体验小样 · 2026-10-29

意图：优化 UI／在既有白纸文档方向内整理。阶段：可操作小样，等待用户看效果；没有替换正式模板、生成器或已安装 Skill 的产物。

北极星：先看清合作要求，再根据现有素材比较选题，按需读拍法。

## 范围与依据

- 用户已认可先前诊断，并要求用 oil-ui-pro 模拟改正后的样子。本轮将诊断落实为四项：重点层级、展开后的阅读负担、选题比较、展开入口。
- 既有规范继续有效：纯白、黑灰文字、四个主问题、紧凑品牌栏、不新增合作标题；必拍与禁区默认可见；来源可核对；报告可离线打开。
- 保留现有字体、图标、原 brief 及 Star 入口。内容阅读任务不需要新增配图。
- 内容来自 `examples/report.json` 的虚构“随剪”合作。重排和缩写属于此小样，品牌事实与要求不新增；原始示例 JSON 没有修改。日期保留原材料，未因演示日期变化而更新。

## 四项变化

1. 重点层级：主推名称加大；交脚本、发布视频改成独立交付项，明确年份、时区；必拍流程保持默认可见。
2. 详情编排：产品按输入、工具处理、人工判断、产物分组；说明控制行长；视频推进改为具体步骤。
3. 选题比较：默认并列显示选题、准备素材、产物；手机按相同字段堆叠。每个选题独立展开，避免一次展开全部长文。四项选题内容仍保留。
4. 展开入口：加号配具体文字，展开后显示收起；保留键盘与触屏操作。

这些是 Agent 的小样设计取值，尚未成为用户确认的正式规范。主推字号、日期布局与选题展开方式等正式接入后再写入根目录 `DESIGN.md`。

## 文件与复现

- `report.html`：单文件可操作小样，内嵌字体、数据、图标、样式和脚本。
- `style-explorer.html`：oil-ui-pro 生成的前后对比页，可并排或单张体验。对比工具的离线候选会把外部导航链接视为资源，因此采用其本机 URL 模式，需下列预览服务；两个报告 HTML 本身均可独立打开。
- `current.html`：正式虚构样例的画面与内容快照，只缩减内嵌字体的字库，排版与交互不变。
- `template.html`、`build_preview.py`：小样源文件与构建工具，不参与正式报告生成。
- `manifest.json`：同事实、同视口的对比配置，以及仅绑定本机的服务启动命令。

重建小样需要 Python 与 FontTools/Brotli（仅用于缩减固定示例的内嵌字体）；查看 HTML 无需安装依赖。正式生成器仍只依赖 Python 标准库。

```powershell
python design-exploration/02/build_preview.py
python C:/Users/32834/.agents/skills/oil-ui-pro/scripts/build_explorer.py design-exploration/02/manifest.json --force

```

动效沿用轻量反馈：按下反馈、加号变减号、展开内容短暂过渡、来源弹窗出场；减少动态效果时直接显示。保留立即可读的页面，不新增首次进入或滚动叙事。
